# AI辅助出行 - 智能导航系统

面向视障人士的 AI 辅助出行系统，支持盲道导航、过马路辅助、红绿灯检测、物品搜索、AI 语音对话。

---

## 系统要求

- Python 3.10/3.11（推荐，3.13 需额外处理）
- NVIDIA GPU + CUDA 11.8（可选，CPU 模式较慢）
- Android 8.0+ 手机
- 阿里云 DashScope API Key

## 快速开始

### 1. 安装 Python 依赖

```bash
pip install -r requirements.txt
pip install torch==2.0.1+cu118 torchvision==0.15.2+cu118 --index-url https://download.pytorch.org/whl/cu118
```

如果使用 CPU 模式：
```bash
pip install torch torchvision
```

Windows 上 pyaudio 可能需要手动安装：
https://www.lfd.uci.edu/~gohlke/pythonlibs/#pyaudio

### 2. 配置 API Key

编辑 `.env` 文件，填入你的 DashScope API Key：
```
DASHSCOPE_API_KEY=你的Key
```

申请地址：https://dashscope.console.aliyun.com/

### 3. 启动服务器

```bash
python app_main.py
```

服务器运行在 http://localhost:8081

### 4. 安装手机 App

将 `AIGlass-demo.apk` 安装到 Android 手机。

- 打开 App → 点击右上角齿轮图标
- 输入电脑的局域网 IP 地址和端口 8081
- 保存后自动连接

### 5. 使用语音指令

| 指令 | 功能 |
|---|---|
| "开始导航" / "盲道导航" | 启动盲道导航 |
| "开始过马路" | 启动过马路模式 |
| "检测红绿灯" | 红绿灯检测 |
| "帮我找一下矿泉水" | 物品搜索 |
| "帮我看看这是什么" | AI 拍照识别 |
| 任意问题 | AI 语音对话 |

## 项目结构

```
├── app_main.py              # 主入口，FastAPI 服务器
├── navigation_master.py     # 导航状态机
├── workflow_blindpath.py    # 盲道导航
├── workflow_crossstreet.py  # 过马路导航
├── yolomedia.py             # 物品搜索
├── asr_core.py              # 语音识别 (ASR)
├── omni_client.py           # AI 多模态对话
├── audio_player.py          # 音频播放
├── audio_stream.py          # 音频流推送
├── model/                   # AI 模型文件（必需）
├── music/                   # 导航提示音
├── voice/                   # 语音提示文件
├── android_app/             # Android 客户端源码
├── AIGlass-demo.apk         # Android 安装包
└── requirements.txt         # Python 依赖
```

## Android 客户端开发

用 Android Studio 打开 `android_app/` 目录即可编译修改。

技术栈：Kotlin + Jetpack Compose + CameraX + OkHttp WebSocket

## 模型文件说明

| 文件 | 用途 |
|---|---|
| yolo-seg.pt | 盲道分割 |
| yoloe-11l-seg.pt | 障碍物检测 |
| shoppingbest5.pt | 物品识别 |
| trafficlight.pt | 红绿灯检测 |
| hand_landmarker.task | 手部关键点 |

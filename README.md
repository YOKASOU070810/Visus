# Visus - 视障人士智能出行助手
一款专为视障人群打造的安卓智能出行应用，基于阿里大模型赋能，集精准导航、路况感知、应急处理、智能语音与家庭联动于一体。

## 项目简介
Visus 是面向**视障人群**的专属安卓移动端应用，依托阿里大模型的强大AI能力，解决视障人士户外出行的核心痛点。
应用提供米级高精度导航、实时路况检测、突发事件应急处理、个性化AI语音交互，搭配家庭组群实时联动功能，为视障用户打造安全、便捷、有温度的出行体验。

## 核心功能
### 1. 米级高精度导航
- 步行场景米级精准定位与路线规划
- 全语音导航播报，无视觉依赖操作
- 智能避让危险路段，适配视障出行习惯

### 2. 实时路况检测
- AI 实时识别障碍物、交通信号、路面状况
- 阿里大模型智能风险分析与提前预警
- 纯语音路况提示，解放双手与双眼

### 3. 突发事件处理
- 一键紧急求助，自动发送实时位置给家人
- 智能识别跌倒、被困等异常场景，主动触发应急机制
- 快速联动紧急联系人，保障用户人身安全

### 4. 个性化AI语音系统
- 基于阿里大模型的自然语言语音交互
- 支持自定义语音音色、播报语速、提醒模式
- 全语音指令控制，覆盖出行全场景操作

### 5. 家庭组群模块
- 创建家庭群组，实时共享出行位置
- 家人可查看行程轨迹、接收安全状态通知
- 双向语音通讯，随时随地保持沟通

## 技术栈
- **客户端**：Android (Java/Kotlin)
- **AI 引擎**：阿里通义大模型
- **定位导航**：米级高精度定位 SDK、地图导航引擎
- **语音技术**：语音识别(ASR)、语音合成(TTS)
- **通讯服务**：实时位置共享、即时通讯
- **感知算法**：实时路况分析、应急事件检测

## 项目特色
- 全功能无视觉依赖，纯语音交互，深度适配视障用户
- 阿里大模型深度赋能，智能感知与决策更人性化
- 三重安全保障：路况预警、应急处理、家庭联动
- 极简操作，一键交互，降低使用门槛
- 个性化配置，满足不同用户的使用习惯

## 安装与使用
1. 安装 APK 到安卓设备
2. 授权定位、麦克风、存储、通话等必要权限
3. 注册账号并配置个性化语音参数
4. 创建/加入家庭组群，绑定紧急联系人
5. 开启导航/路况检测，即可安全出行
